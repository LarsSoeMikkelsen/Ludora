Honest description

What Ludora actually is right now.

Ludora is a personal project to build a gaming-focused Linux distro on top of Fedora 43. The idea is simple: take a solid RPM base, replace the kernel with something faster, provide a dedicated repo with the newest stable drivers and ship only the tools a gamer actually uses, and skip everything else.

Right now it exists as a COPR repository — a set of custom-built packages on top of a standard Fedora 43 install. The ISO and installer is not ready for public use yet.

The name comes from ludo (Latin for "I am playing") and Fedora, the base it's built on. The goal is a distro where you install it, open Steam, and play — no touching a config file or hunting for drivers, but without compromising performance.

If that sounds interesting to you, watch the COPR and this space. Things are moving.

Roadmap

Where this is going.

No promises, no deadlines. Just an honest list of what's done and what's next.

  • Done
    Custom kernel builds kernel-ludora 6.19.3 with BORE scheduler and CachyOS patches building cleanly on COPR.
  • Done
    Maintained Mesa stack Mesa 26.0.0 and libva 2.23.0 built and tracked independently of Fedora upstream.
  • Done
    Gaming tooling packages MangoHud, GOverlay, ProtonPlus, and Fastfetch all building in COPR.
  • Done
    Steam + Proton-GE preinstalled Gaming-ready out of the box — no post-install setup required.
  • Done
    Ludora KDE theme A custom Ludora KDE theme.
  • Done
    Kickstart / image definition A reproducible image definition that installs a Fedora 43 base with all Ludora packages applied.
  • In progress
    Proper bootable ISO An actual ISO someone can write to a USB drive and install. The real milestone.
  • Later
    Public release When it's actually good enough to hand to someone else without instructions.
